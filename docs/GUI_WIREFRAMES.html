Question and teacher answer

Write solve(text) without reverse() or negative-step slicing. The empty string is a palindrome.

def solve(text):
    left, right = 0, len(text) - 1
    while left < right:
        if text[left] != text[right]:
            return False
        left += 1
        right -= 1
    return True
